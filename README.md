# Rodhareist

Futureboard Studio's guitar multi-effect as a VST3, CLAP and VST2 plug-in for Windows.

**Download:** get the installer from [Releases](https://github.com/futureboard/rodhareist-release/releases/latest).

This repository only hosts release builds. Rodhareist is developed in [Futureboard Studio](https://github.com/futureboard/futureboard-studio).
